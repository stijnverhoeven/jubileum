# Tower Defense

Een vanilla HTML5/canvas tower defense spel, zonder build-stap.

## Spelen

Open `index.html` in een browser, of serveer de map lokaal:

```
python3 -m http.server 8000
```

en ga naar `http://localhost:8000`.

## Spelregels

- Plaats torens (Boogschutter, Kanon, Sluipschutter, Vrieskanon) langs het pad om golven vijanden tegen te houden.
- Elke gedode vijand levert goud op; elke vijand die het einde van het pad haalt kost een leven (bosses kosten 5).
- Klik "Start Wave" om de volgende golf te starten. Klik op een geplaatste toren om te upgraden of te verkopen.
- Overleef alle 20 golven om te winnen.
